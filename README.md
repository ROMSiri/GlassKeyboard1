# Glass Keyboard

Android-клавиатура (IME) с эффектами материала ColorOS 17 из модуля WeTypeColorOSMaterial:

- **Размытая панель**: на ColorOS — системный материал через `com.oplus.view.ViewRootManager` + `OplusBlurParam` (радиус 150, тон `#CCE1E1E1` / `#990D0D0D`, верхние углы 28dp, гладкие G2-углы). На Android 12+ — размытие окна `Window.setBackgroundBlurRadius` (углы прямые: AOSP не умеет скруглять область блюра). Иначе — почти непрозрачная панель.
- **Стеклянные клавиши**: свой AGSL-шейдер `res/raw/glass_material.agsl` — суперэллиптические углы, полупрозрачная заливка, внутреннее свечение у нижнего края, тонкая кромка, яркая по диагонали света. Ниже Android 13 — упрощённая версия на градиентах.
- **Кромка панели** (аддитивное смешивание), круглые кнопки панели инструментов, всплывающие подсказки, анимация нажатия.
- Цвета клавиш взяты из модуля: светлая `#8AFFFFFF` / нажатая `#85BBBEC2`, тёмная `#26FFFFFF` / `#3DFFFFFF`.

Функции: русская (ЙЦУКЕН) и английская раскладки, символы (2 страницы), Shift/Caps Lock (двойное нажатие), долгое нажатие — цифры, ё, ъ и другие символы, повтор Backspace, перемещение курсора свайпом по пробелу, долгое нажатие на пробел или 🌐 — выбор клавиатуры, автозаглавная, двойной пробел даёт точку, кнопка Enter учитывает действие поля (поиск, отправка, далее, готово), вставка, вибрация и звук. Тема следует системной.

## Возможности (1.5)

**Подсказки и исправление текста** — словари RU (220 тыс.) и EN (160 тыс.) из AOSP, исправление опечаток с учётом соседних клавиш, автоисправление при пробеле (⌫ сразу после — отмена), три уровня точности, сокращения («щас» → «сейчас», «wont» → «won't»), блокировка нецензурных слов, подсказка следующего слова, обучение на ваших словах, личный словарь, 3 или 5 подсказок, средняя подсказка по пробелу, эмодзи-подсказки и поиск «:слово», знаки препинания и буфер обмена в полосе, имена контактов и приложений, системный личный словарь Android, варианты для слова под курсором, служба проверки правописания для других приложений.

**Панель инструментов** — режимы «Расширяемая», «Только клавиши», «Только подсказки», «Скрыта»; 27 клавиш (голос, отмена/повтор, выделение, копировать/вырезать/вставить, курсор, страницы, цифровая панель, одна рука, высота клавиш, инкогнито, автоисправление, скрыть) с выбором и порядком, закреплённые и постоянная клавиши, смахивание вниз для скрытия, свои коды клавиш.

**Непрерывный ввод** — набор слов жестами (свой декодер траектории), след, плавающий предпросмотр, фразы через пробел, пауза после быстрой печати, время жизни следа, автопробелы.

Эмодзи-ключевые слова собираются при сборке в CI из Unicode CLDR (`tools/emoji`), словари — `tools/dicttool`.

## Сборка

Тот же тулчейн, что и у WeTypeColorOSMaterial: JDK 21, Android SDK 37, AGP 9.3.1, Gradle 9.7.1 (wrapper в проекте). Зависимостей нет.

```powershell
.\gradlew.bat :app:assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk` (подписан debug-ключом, для своего распространения замените signingConfig).

## Установка

1. Установите APK и откройте «Glass Keyboard».
2. «Включить в настройках» → включите Glass Keyboard.
3. «Выбрать клавиатуру» → Glass Keyboard. Проверить можно в поле ниже.

## Файлы

| Файл | Что делает |
|---|---|
| `GlassKeyboardService` | InputMethodService: ввод текста, Enter, курсор, автозаглавная, привязка блюра |
| `KeyboardView` | вся отрисовка и мультитач |
| `GlassPainter` | материал клавиш/кнопок/кромки (AGSL + запасной вариант) |
| `PanelBlur` | блюр ColorOS → блюр Android 12 → без блюра |
| `Layouts` | раскладки |
| `SettingsActivity`, `Prefs` | настройки |
